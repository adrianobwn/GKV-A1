# 🌐 3D Circle with Lighting Simulation - OpenGL

## 📄 Description
This project demonstrates a simple 3D simulation using OpenGL that displays a 3D circle with basic lighting. The simulation allows the user to move and rotate the camera in 3D space using keyboard input, and it also displays a grid and a circle in the 3D scene. Basic lighting is applied to enhance the visualization of the objects in the 3D space.

The functions used in this project include:

- **`Reshape()`**: Adjusts the viewport and projection matrix when the window is resized.
- **`orientMe()`**: Rotates the camera around the scene based on the input angle.
- **`moveMeFlat()`**: Moves the camera forward or backward.
- **`Grid()`**: Draws a grid in the 3D space.
- **`Lingkaran()`**: Draws a 3D circle.
- **`display()`**: Renders the scene, updates the camera, and swaps buffers.
- **`pressKey()`**: Handles camera rotation and movement with arrow keys.
- **`releaseKey()`**: Stops movement or rotation when keys are released.
- **`lighting()`**: Sets up basic lighting for the scene.

This simulation allows user interaction for moving the camera and rotating objects using the arrow keys on the keyboard.

## 🌟 Features
- **3D Circle Simulation**: Displays a 3D circle that can be rotated based on user control.
- **Camera Controls**: Move and rotate the camera in 3D space using the arrow keys.
- **Grid**: A grid is added to the 3D space for visual reference of object positions.
- **Lighting**: Basic lighting is applied to the scene for better object illumination.
- **Keyboard Controls**:
  - **Left/Right Arrow Keys**: Rotate the camera around the scene.
  - **Up/Down Arrow Keys**: Move the camera forward or backward in the scene.
  - **Esc**: Exit the program.
