# 📚 GKV Assignment

## 📄 Description
This repository contains practical assignments for the course Grafika dan Komputasi Visual (Visual Graphics and Computation). The tasks cover various concepts and implementations in computer graphics using the C++ programming language.

## Practical Assingment

- **📄Description**: This project is a 2D car simulation built using OpenGL (GLUT). The project demonstrates basic 2D graphics concepts, including drawing simple shapes to create a car object with a background.
- **🔗 File**: [Tugas Praktikum Pertemuan 2](https://github.com/adrianobwn/GKV-A1/tree/main/Tugas%20Praktikum%20Pertemuan%202)
