# 📚 GKV Assignment

## 📄 Description
This repository contains practical assignments for the course Grafika dan Komputasi Visual (Visual Graphics and Computation). The tasks cover various concepts and implementations in computer graphics using the C++ programming language.

## Practical Assingment
### 📌 Practical Assingment for Meeting 2
- **📄Description**: This project is a 2D car simulation built using OpenGL (GLUT). The project demonstrates basic 2D graphics concepts, including drawing simple shapes to create a car object with a background.
- **🔗 File**: [Tugas Praktikum Pertemuan 2](https://github.com/adrianobwn/GKV-A1/tree/main/Tugas%20Praktikum%20Pertemuan%202)

### 📌 Practical Assingment for Meeting 3
- **📄 Description**: This project demonstrates a 3D arm and finger animation built using OpenGL (GLUT). The simulation includes basic body parts such as the upper arm, lower arm, palm, and fingers. The project uses basic transformations like translation and rotation to simulate the movement of each arm segment.
- **🔗 File**: [Tugas Praktikum Pertemuan 3](https://github.com/adrianobwn/GKV-A1/tree/0d68e3e612f00adb21e6fdf50a2be28bf6053bca/Tugas%20Pertemuan%203)

### 📌 Practical Assingment for Meeting 4
- **📄 Description**: This project is a 3D circle simulation with lighting and camera controls using OpenGL. Users can change the camera angle and position using the keyboard. The scene includes a floor grid and a 3D circle illuminated with lighting.
- **🔗 File**: [Tugas Praktikum Pertemuan 4](https://github.com/adrianobwn/GKV-A1/tree/775a4dc1310b325ad969088763332f86678e7d72/Tugas%20Pertemuan%204)
